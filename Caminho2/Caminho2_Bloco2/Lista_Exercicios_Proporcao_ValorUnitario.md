# Exercícios — Proporção e raciocínio multiplicativo

**1)** Uma banca de ovos vende uma bandeja com 6 ovos por R$ 12. Dona Rita quer comprar só metade da bandeja, ou seja, 3 ovos. Quanto ela vai pagar?

C) R$ 6
D) R$ 7

A) R$ 8

D) R$ 11
E) R$ 12

## Gabarito

| Questão | Resposta | Tipo de raciocínio |
|---|---|---|
| 1 | C | Valor unitário simples (um só tipo de item) |
| 2 | C | Valor unitário com dois tipos de item |
| 3 | C | Equivalência entre unidades |
| 4 | C | Equivalência entre unidades |
| 5 | C | Duas etapas, arredondando para cima |
| 6 | C | Valor unitário com dois tipos de item |
| 7 | C | Equivalência entre unidades |
| 8 | C | Duas etapas, arredondando para cima |
| 9 | B | Duas etapas, arredondando para baixo (grupos completos) |
| 10 | D | Equivalência entre unidades, com pista de preço redundante |

**Notas rápidas para quem for corrigir:**
- Nas questões 5 e 8, a alternativa B é o resultado direto da divisão sem arredondar (6,25 e 5,4). Ela mostra o erro de esquecer que um pacote não pode ser comprado pela metade.
- Na questão 9, a pergunta pede fileiras completas, não o total de mudas usadas, por isso o arredondamento é para baixo, ao contrário das questões 5 e 8.
- Na questão 10, os preços das caixas de suco não servem para nada na conta final. A pergunta é sobre copos, não sobre dinheiro, e essa pista solta serve para treinar quem confunde "informação dada" com "informação necessária".
